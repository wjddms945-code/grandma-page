가족장 진행 정리

메디힐병원 → 벽제 화장장 → 유토피아

가족끼리 확인할 핵심 내용만 정리한 모바일용 요약 페이지

1. 진행 순서

서남병원 → 메디힐병원
메디힐병원 가족장 2박 3일
발인 후 벽제 화장장 이동
화장 후 유골함 수습
유토피아 납골당 안치

2. 메디힐병원 기본 내용

  • 5호실 기준
  • 기본 비용: 239만원
  • 포함 항목: 수의, 관, 장의용품, 상복, 입관비용, 안치실 사용료
  • 염습은 장례지도사 2명 진행

3. 추가 비용

화장 예약 + 시설 이용12만원
영정사진 꽃장식50만원
버스 대절
메디힐 → 벽제49만 8천원
남자 정장 대여
집 정장 착용 시 무료1벌 3만 5천원
식사-별도로 먹어도됨.원하면추가 가능
예상: 361만 8천원 + 식사비

남자 정장 대여 필요? (아빠,이모부,민호). 식사는 사용량에 따라 비용 변동.

4. 식사 / 도우미

  • 식사는 기본 비용에 포함되지 않음
  • 장례식장 제공, 외부 식사, 개별 준비 모두 가능
  • 장례식장 식사는 외부에서 사 먹는 것보다 저렴하게 제공 가능하다고 함
  • 가족장이라 도우미는 보통 필요 없다고 안내받음
  • 필요 시 도우미 1명 가능 / 시급 1만 5천원

5. 이동 기준

  • 서남병원 → 메디힐병원: 24시간 무료 제공
  • 메디힐병원 → 벽제 화장장: 버스 49만 8천원
  • 버스 비용은 기사님께 직접 지급
  • 벽제 → 유토피아는 버스 비용에 포함되지 않음
  • 화장 후 유골함만 들고 개인 승용차 이동 추천

6. 유토피아에 확인할 것

  • [계약전-6월9일 진행하기로]-확인필요.바로 계약가능한지
  • 계약금 10만원 드린상태
  • 화장 후 당일 안치 가능 시간
  • 필요 서류: 사망진단서, 화장증명서? 등
  • 기존 계약 외 추가 비용 여부
  • 관리비 발생 시점과 금액-1년 7만원-35만원선납
  • 유골함 별도 구매 필요 여부
  • 가족 동행 가능 인원

7. 현재 결정 방향

  • 메디힐병원 가족장 진행
  • 영정사진 꽃장식 진행
  • 버스는 메디힐 → 벽제까지만 이용
  • 벽제 → 유토피아는 개인 승용차 이동
  • 식사는 상황 보고 결정
